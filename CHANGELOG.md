## [1.0.0] - 2026-03-16

### Added

- Initial curated list with 15 categories covering the AI agent orchestration ecosystem
- Protocols & Standards: MCP, A2A, ACP, ANP with comparison table
- Multi-Agent Frameworks: 20+ production-grade and emerging frameworks
- Autonomous Coding Agents: OpenHands, SWE-agent, Aider, Cline, and more
- Coding Agent Orchestrators: 30+ parallel agent runners and IDE-integrated platforms
- Chinese AI Orchestration: AI Imperial Court (Edict), CCB, Dify, MetaGPT, DeerFlow
- Low-Code / Visual Platforms: Dify, n8n, Flowise, LangFlow, RAGFlow
- Observability & Evaluation: Langfuse, Arize Phoenix, AgentOps, Laminar
- Agent Infrastructure: E2B, Daytona, Composio, Browserbase, Firecrawl
- Personal AI Assistants: OpenClaw, Leon, BabyAGI, Happy, Letta
- Autonomous Loop Runners: ralph-orchestrator, loom, and variants
- Multi-Agent Swarms: claude-flow, ruflo, gastown, OASIS
- Benchmarks: SWE-bench, MultiAgentBench, AgentBench, WebArena
- Academic Papers: 25+ papers across surveys, protocols, reasoning, and coding agents
- Courses & Tutorials: 15+ courses from DeepLearning.AI, Coursera, Udacity, Udemy
- Learning Resources: articles, comparisons, and related awesome lists
- Bilingual content (English / Chinese) throughout
- CONTRIBUTING.md with guidelines
- Repository infrastructure (issue templates, PR template, LICENSE)
